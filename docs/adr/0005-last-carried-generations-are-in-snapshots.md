# When each Allele was last carried is part of Snapshots

Each retained Allele in the Allele Tree records the latest Generation a live Cell carried it in, and Snapshots carry it (format version 4; version 3 is no longer read). The Allele Tree view draws every Allele from its origin to when it was last carried, and an extinct Allele that is still retained, as a Founding Allele or as the ancestor of a living one, needs that end point. The page only takes a census while the side panel is open, so it cannot work this out by watching the run; the core is the only place that sees every Generation. It costs 8 bytes per retained Allele and one write per carried Allele copy at the pruning the World already does each Generation. Like Birth Generations (ADR-0004), it never changes which Cells live, so it is included for the view, not for determinism.
